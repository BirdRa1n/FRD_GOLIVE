FRD GoLive

Aplica a modificação no Discord para transmissão de tela/câmera privada.

O que a modificação faz (e sobre a senha de administrador)
  • Injeta o Vencord (client mod) no seu Discord e ativa o plugin FRD GoLive.
  • Grava as settings do plugin e uma regra de CSP liberando só o domínio do seu servidor.
  • Ao aplicar, o sistema pode pedir sua senha de administrador — é o passo que modifica o app do Discord (no macOS, quando ele está em /Aplicativos). Nada é enviado a terceiros nem alterado fora dos dados do app e do Discord.
  • Feche o Discord antes de aplicar; reabra depois.

✔ Modificação aplicada!

Agora entre no site para habilitar o uso do servidor. Quando o admin liberar, o Discord já notifica e liga as funções.
