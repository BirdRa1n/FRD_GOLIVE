O que a modificação faz
  • Injeta o Vencord (client mod) no seu Discord e ativa o plugin FRD GoLive.
  • Grava as configurações do plugin e uma regra de CSP liberando só o domínio do seu servidor.
  • O sistema pode pedir sua senha de administrador — é o passo que modifica o app do Discord (no macOS, quando ele está em /Aplicativos). Nada é enviado a terceiros.
Feche o Discord antes de aplicar e abra de novo depois.

Pronto!

Agora entre no site para pedir acesso. Quando o admin liberar, o Discord liga as funções sozinho.
