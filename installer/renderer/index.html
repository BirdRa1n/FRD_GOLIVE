Grupos habilitados

Enviar logs a cada 5 minutos
Console do Discord, conexão e estatísticas de mídia, incluindo IDs de usuário/canal e IPs de conexão. Tokens são removidos. Vão só para o servidor acima.
Sem os logs, fica impossível a gente encontrar eventuais erros, como as quedas de conexão com o Discord.
O que a modificação faz
  • Injeta o Vencord (client mod) no seu Discord e ativa o plugin FRD GoLive.
  • Grava as configurações do plugin e uma regra de CSP liberando só o domínio do seu servidor.
  • Se o envio de logs estiver ligado, manda os logs do Discord (sem tokens) só para o servidor acima, a cada 5 minutos.
  • O sistema pode pedir sua senha de administrador. É o passo que modifica o app do Discord (no macOS, quando ele está em /Aplicativos). Nada é enviado a terceiros.
Feche o Discord antes de aplicar e abra de novo depois.

Pronto!

Entre no site para pedir acesso. Quando o admin liberar, o Discord liga as funções sozinho.
